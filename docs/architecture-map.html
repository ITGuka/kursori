მაგალითად, სტუმარი ხსნის მისამართს /ka/fasebi:

1 · მისამართიRouter/{lang}/{slug}-ს ადარებს მარშრუტებს (app/routes/web.php)
→
2 · შემოწმებებიMiddlewareენა აქტიურია? ტექ. სამუშაოები ხომ არ მიმდინარეობს? გვერდი ქეშში ხომ არ არის?
→
3 · მონაცემებიPageControllerპოულობს გვერდს slug-ით და იღებს მის აქტიურ ბლოკებს
→
4 · ბლოკებიBlockResolverველებს ამზადებს მიმდინარე ენაზე. თუ თარგმანი აკლია, იღებს ქართულს. კოლექციიდან ჩანაწერებს ავსებს
→
5 · HTMLViewsთითო ბლოკი თავის შაბლონში იხატება (views/front/blocks/), შემდეგ ყველაფერი layout-ში ერთიანდება

სტუმრებისთვის მზა HTML ქეშდება. ადმინში ნებისმიერი ცვლილება ქეშს წმენდს, ამიტომ განახლებული გვერდი მაშინვე ჩანს. ადმინში შესულ მომხმარებელს მონახაზებიც უჩანს.

09 · დეველოპერისთვის

ფაილების სტრუქტურა

კოდი ორ ფენადაა გაყოფილი. core/ არის საერთო ფრეიმვორკი, რომელიც სხვა პროექტშიც გამოდგება. app/ არის ამ საიტის კოდი. ახალი ბლოკი, კოლექცია ან ფორმა ძირითადად კონფიგში ემატება.

KURSORI/
├─ core/            ფრეიმვორკი: Router, Request/Response, DB, Auth, View, Mailer, Cache, Validator
├─ app/
│  ├─ Controllers/    Front/ (გვერდები, ფორმები, შეკვეთა) · Admin/ (ყველა ადმინ-სექცია)
│  ├─ Models/         Page, PageBlock, Collection, Category, Design, Media, Menu …
│  ├─ Blocks/         BlockInput (ადმინის ფორმა + ვალიდაცია) · BlockResolver (ფრონტის მონაცემები)
│  ├─ Middleware/     SetLocale, CheckMaintenance, PageCache, Authenticate …
│  ├─ Services/       Newsletter, TemplateArchive (დიზაინის ZIP)
│  └─ routes/         web.php (საიტი) · admin.php (ადმინი)
├─ config/          blocks.php · collections.php · forms.php · settings.php · admin.php (მენიუ)
├─ views/
│  ├─ front/          layouts/main · blocks/ (თითო ბლოკის შაბლონი) · collections/ · partials/
│  ├─ admin/          DASHMIN თემაზე
│  └─ emails/         წერილების შაბლონები
├─ database/        migrations/ (ცხრილები) · seeds/ (საწყისი კონტენტი)
├─ public/          index.php · assets/ (Kursori თემა, site.css, JS) · uploads/ (მედია, დიზაინები)
├─ storage/         ქეში და ლოგები
└─ bin/console      migrate · db:seed · cache:clear · content:reset …

როგორ დავამატო…

ახალი ბლოკის ტიპი: ჩანაწერი config/blocks.php-ში (ველები) და შაბლონი views/front/blocks/{type}.php. ადმინის ფორმა ავტომატურად შეიქმნება.

ახალი კოლექცია: ჩანაწერი config/collections.php-ში. ადმინის მენიუში თავისით გამოჩნდება, მიგრაცია არ სჭირდება.

ახალი პარამეტრი: ერთი ხაზი config/settings.php-ში. საჭირო ადგილას იკითხება setting('group.key')-ით.
